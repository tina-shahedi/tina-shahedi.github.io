# tina-shahedi.github.io

Personal website and portfolio of **Tina Shahedi** — Junior Researcher in Methodology & Statistics at Utrecht University.

🔗 **Live site: [tina-shahedi.github.io](https://tina-shahedi.github.io/)**

## What's on the site

- **About & Skills** — background and toolset
- **Resume** — professional experience and education
- **Projects & Publications** — research work with links to papers and code
- **Certificates** — completed courses and training
- **Organizations & Contact** — affiliations and ways to get in touch

## Built with

- HTML5, CSS3, and vanilla JavaScript
- Bootstrap 5, AOS, GLightbox, Swiper
- Based on the [MyResume](https://bootstrapmade.com/free-html-bootstrap-template-my-resume/) template by [BootstrapMade](https://bootstrapmade.com/), heavily customized
- Hosted on **GitHub Pages**

## Repository structure

```text
.
├── index.html          # single-page site
├── assets/
│   ├── css/            # main stylesheet
│   ├── js/             # site scripts
│   ├── img/            # photos, certificates, favicons
│   ├── docs/           # CV and documents
│   └── vendor/         # Bootstrap, AOS, GLightbox, Swiper
└── forms/              # contact form handler
```

## Run locally

```bash
git clone https://github.com/tina-shahedi/tina-shahedi.github.io.git
cd tina-shahedi.github.io
python3 -m http.server 8000
# then open http://localhost:8000
```
